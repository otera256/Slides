# 自作トラッカーの技術補足

本編の11〜15枚目を説明するための発表者向けノート。以下の式は、参照会話の構想を整理した**設計モデルとその導出**であり、実機で成立を確認した推定器ではない。記号は、p：部屋内の位置、v：速度、R：センサー座標から部屋座標への回転、q：同じ姿勢を表す単位クォータニオン。

## A. IMUが測る量とドリフト

### 加速度計とジャイロ

部屋座標での重力加速度ベクトルを g とすると、加速度計の観測は概念的に

\[
\mathbf f_m=R^\top(\ddot{\mathbf p}-\mathbf g)+\mathbf b_a+\mathbf n_a
\]

となる。f_mは比力であり、世界座標の移動加速度そのものではない。姿勢とバイアスが分かれば

\[
\ddot{\mathbf p}=R(\mathbf f_m-\mathbf b_a)+\mathbf g
\]

から速度・位置を積分できる。静止時にも f_m はおよそ −Rᵀg となる。

ジャイロは角速度 ω を測り、その積分で姿勢を更新する。3Dでは回転の順序が効くため、単純に3軸の角度を足す説明より、回転行列またはクォータニオンで回転を合成する説明が適切。「角度をさらに積分して向きにする」操作はない。

### 誤差の概算

一定の世界座標加速度誤差 δa が残った場合、初期誤差をゼロとすれば

\[
\delta p(t)=\tfrac12\delta a\,t^2.
\]

δa = 0.01 m/s²、t = 10 s で δp = 0.5 m。これは特定IMUの性能値ではなく、二重積分の影響を示す例。

姿勢に1°の傾き誤差があると、重力の水平成分の取り違えはおよそ g sin(1°) ≈ 0.17 m/s²。小さな姿勢誤差も位置へ大きく効く。加速度計を重力方向の観測として使えるのは、運動加速度を無視・推定できる条件であり、激しく動いている間には区別が難しい。

SlimeVRでは姿勢と骨長から順運動学で身体を再構成する。HMDの位置が基準となり、IMU単体の慣性航法とは位置の作り方が異なる。6軸IMUの「6軸」は加速度3軸＋角速度3軸を意味し、絶対6DoFを単独で計測できるという意味ではない。

出典：[SlimeVR 101](https://docs.slimevr.dev/slimevr101)、[Woodman（2007）](https://www.cl.cam.ac.uk/techreports/UCAM-CL-TR-696.html)。古い論文の装置の誤差数値を、現在のセンサーの性能へ流用しない。

## B. 磁場マップの順問題と逆問題

### 形と電流から磁場を計算する

細い空芯導線を仮定したBiot–Savartモデルは

\[
\mathbf B_k(\mathbf p)=\frac{\mu_0N_kI_k}{4\pi}
\oint_{C_k}\frac{d\boldsymbol\ell\times(\mathbf p-\mathbf r')}{\|\mathbf p-\mathbf r'\|^3}.
\]

ここでC_kは導線の経路、r′はその位置、N_kは同じ経路の巻数。実際の巻線の広がりや往復配線も、必要な精度に応じてモデルへ加える。

コイル径より十分遠ければ、磁気モーメント μ = NIA n の双極子としておおむね B ∝ r⁻³ になる。部屋サイズのコイルの内部や近傍へ、この遠方近似をそのまま使わない。

### 磁場から位置・姿勢を求める

静止・同期済みの差分観測 d_k に対して

\[
(\hat{\mathbf p},\hat q)=\arg\min_{\mathbf p,q}
\sum_k\left\|\mathbf d_k-R(q)^\top\mathbf B_k(\mathbf p)\right\|_{\Sigma_k^{-1}}^2
+\text{IMU等による事前拘束}
\]

という重み付き最小二乗を考えられる。\(\|r\|_W^2=r^\top Wr\)。ノイズが大きい方向の観測は重みを下げる。初期位置が不明なら、複数の初期値や粗い地図探索を使い、局所的に合った別解へ吸い込まれる可能性を検査する。

「大きさだけ」では方向の情報を捨ててしまう。一方、3軸ベクトルを使うと姿勢の影響を受ける。位置・姿勢を同時に考える必要がある。

出典：[OpenStax：Biot–Savart則](https://openstax.org/books/university-physics-volume-2/pages/12-1-the-biot-savart-law)。最小二乗式は、この発表の観測モデルから構成した設計案。

## C. 反転差分の観測モデル

### 差分で消える条件

磁気センサーのゲイン・軸ずれを較正した後の観測を

\[
\mathbf m_s=R^\top\{\mathbf B_{\rm env}(\mathbf p)+s\mathbf B_k(\mathbf p)\}
+\mathbf b_m+\mathbf n_s,\quad s\in\{-1,0,+1\}
\]

とする。正負の電流の絶対値が同じで、測定間にp・R・背景場・オフセットが変わらなければ

\[
\mathbf d_k=\frac{\mathbf m_+-\mathbf m_-}{2}
=R^\top\mathbf B_k(\mathbf p)+\frac{\mathbf n_+-\mathbf n_-}{2}.
\]

0状態は背景磁場の観測に使えるが、それだけで背景場とセンサーのオフセットを別々に特定できるわけではない。また、「電源を切った瞬間」が即座に電流ゼロになるとは限らない。残留電流とセンサーの整定を確認する。

### 正負電流が非対称なとき

単位電流当たりの磁場を G_k(p) [T/A]、実測した符号付き電流を I_+, I_- とする。静止条件で観測ノイズを除いて考えると、

\[
\frac{\mathbf m_+-\mathbf m_-}{I_+-I_-}=R^\top\mathbf G_k(\mathbf p).
\]

多数のサンプルでは、各軸について m_j = c + I_j g + n_j を回帰して傾きgを求める方法もある。背景cがゆっくり変化するなら時間の項を追加する候補があるが、運動・磁場変動との識別可能性を確認する。単に各測定値をIで割ると背景も割ってしまうため、差分または切片付き回帰で分離する。

### 残る誤差

- 電流に応じた鉄材の磁化や磁場の歪みは、コイル成分とともに残る。
- センサーのゲイン誤差・非直交性は、差分を取っても残る。
- 動作による背景場の見え方の変化、温度変化、ヒステリシスは単純な共通成分にならない。
- コイルごとの場は独立に駆動・観測して初めて別の情報になる。同時に同じ比率で駆動して全体だけを反転すると、得られるのは合成場の一つのパターン。

### 平均とノイズ

各極性で独立なN個を平均し、1サンプルの標準偏差をσと仮定すると、差分の半分の標準偏差は σ/√(2N)。ただし総サンプル数は2Nであり、正負の待ち時間も必要になる。

独立性・白色性が崩れると、単純な1/√N改善は成立しない。内部フィルタ、低周波ノイズ、温度、電源、動作中の平均化を含めて測定する。BMM350のODR（出力データレート）と内部平均設定には組合せの制約があり、最大ODRと最小ノイズを同時に使えると仮定しない。

出典：[BMM350データシート](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bmm350-ds001.pdf)、[Polhemus G4 Appendix B](https://polhemus.com/_assets/img/G4_User_Manual_URM10PH238-D.pdf)。差分・回帰・分散の式は上記モデルからの導出。

## D. 時分割測定と動作中の観測

### 時間の収支

3コイル、各コイルに +I / 0 / −I / 0 の4区間、1区間50 msなら

\[
T_{\rm cycle}=3\times4\times50\ {\rm ms}=600\ {\rm ms}.
\]

これは説明用の時間配分。各区間には切替後の待ち時間と使用する測定窓の両方が入る。平均時間を伸ばすとノイズを減らせる可能性がある一方、動作を同一状態とみなせなくなる。

### 動いていると差分式の条件が崩れる

時刻t_jごとの生観測は

\[
\mathbf m_j=R(t_j)^\top\left[\mathbf B_{\rm env}(\mathbf p(t_j))
+I_j\mathbf G_{k(j)}(\mathbf p(t_j))\right]+\mathbf b_m+\mathbf n_j.
\]

姿勢が変わるだけで、一定の地磁気もセンサー座標では違う数値になる。たとえば背景50 µTを1°回転して見ると、変化のスケールは最大約0.87 µTとなりうる（一次近似の例）。ジャイロで共通座標へ戻せても、位置の変化と、姿勢推定誤差の影響は残る。

段階的には、静止差分、短い観測窓での低速運動、時刻別の観測モデルへ進む。動的推定では背景場を0状態から推定するなど、背景とコイル成分を区別する仕組みも必要。磁気観測がどのコイル・実電流・時刻に対応するかをログへ残す。

### 融合の状態と遅延

候補状態は x = (p, v, q, b_a, b_g)。過去の状態を一定時間保持し、磁場観測を該当時刻へ結びつけて補正する。その後のIMUで現在まで再伝播する。状態保持窓は観測の古さを含む必要がある。

fixed-lag smootherは実装候補の一つ。過去状態の更新と再伝播は、遅延観測に対応するフィルタでも設計できる。いずれも測定時刻を失った平均値を後から使うだけでは、動作中の測定ずれを完全には復元できない。

PCの受信時刻だけに頼らず、センサー時刻とコイル制御時刻を同期する。位置・姿勢と同時にバイアスを推定する場合には、その状態が十分観測できるかも調べる。

出典：[GTSAM FixedLagSmoother](https://borglab.github.io/gtsam/fixedlagsmoother/)。上記の磁気観測への適用は開発案で、GTSAMがこのトラッカーを検証済みという意味ではない。

## E. 観測可能性と精度の見積り

### 信号の強さと位置の分かりやすさ

1次元の局所近似では

\[
\sigma_p\approx\frac{\sigma_B}{|dB/dp|}.
\]

例えば、磁場ノイズ20 nT、勾配2 µT/mなら約1 cm。説明用に置いた数字であり、本コイルの実測値ではない。磁場が大きくても勾配が小さければ位置は分かりにくい。3次元では、最も区別しにくい方向の感度が重要。

### 姿勢も未知として評価する

観測h(p, θ) = [RᵀB_1(p), …]の微小変化を表すJacobian Jを作る。ガウス観測の局所モデルで、共分散Σを状態に依存しない既知値とすると、Fisher情報行列は

\[
F=J^\top\Sigma^{-1}J.
\]

位置3成分・姿勢3成分を求める場合、対応する6列が独立かを調べる。事前拘束を足す場合は、観測が与える情報と事前拘束が補う情報を分けて報告する。単一磁場ベクトルは最大3成分なので、一般の6DoFを単独の瞬間観測で決められない。複数コイルでも配置次第で退化する。

通常の不偏推定・正則性の仮定を置ける場合、CRLBは共分散の下限F⁻¹を与える。姿勢が未知なら、位置だけを取り出した情報量には

\[
F_{p,\mathrm{eff}}=F_{pp}-F_{p\theta}F_{\theta\theta}^{-1}F_{\theta p}
\]

という項が現れる（逆行列が存在する場合）。姿勢を完全既知としてF_ppだけを見る場合より、位置についての情報が減る。事前分布を用いた推定の共分散近似と、通常のCRLBの前提は同一ではないことにも注意する。

### 別の場所に同じ解がないか

局所Jacobianが良くても、大域的に同じ観測を作る位置・姿勢がありうる。離れた状態同士を比較し、異なる初期値から最適化するなどして別解を検査する。コイルをずらす・向きを変えることは、こうした曖昧性を減らす候補であり、コイル数だけでは保証できない。

### 参照画像の79.3%を説明する際

画面には「最悪方向の1σ ≤ 10 mm」「N_eff = 100」「積分1,000 ms」とある。この条件を満たす**空間の割合**であり、「79.3%の確率で位置誤差が1 cm以内」という意味ではない。画面の空間P95も、実機誤差の95パーセンタイルと読み替えない。

画像だけでは、Jacobianの実装、姿勢既知の扱い、合成場か独立モードか、雑音の相関までは検証できない。生コードと計算条件が揃うまで、6DoFの性能証明に使わない。

出典：[Ly et al.：A Tutorial on Fisher Information（2017）](https://arxiv.org/abs/1705.01064)。JとSchur補行列の適用はこの観測モデルについての数理的整理。

## F. 金属と地図の扱い

まずコイル由来の実測場を

\[
\mathbf B_{k,\mathrm{real}}(\mathbf p)=\mathbf B_{k,\mathrm{physics}}(\mathbf p)
+\Delta\mathbf B_{k,\mathrm{room}}(\mathbf p)
\]

と表す。コイルごと、かつ駆動電流に対応した残差地図として扱う。固定環境で応答が再現するなら、格子補間などで地図化する候補になる。正負で非線形・履歴依存の応答がある場合、単純な符号反転モデルも見直す。

地図を作るには観測位置・姿勢の基準が必要。最初は既知位置の治具や独立した光学基準を使う。磁場だけから未知の地図と未知の軌跡を自由に同時学習すると、座標の取り方や地図の歪みを区別できなくなる場合があるため、基準と拘束を設ける。

- 固定した鉄材の応答が安定していれば、地図に取り込める可能性がある。
- 鉄材の移動やヒステリシス、電流や温度の変化は再現性を損なう。
- 銅・アルミなどの非磁性導体は、十分静定したDC場では渦電流の効果が減衰する。一方、切替直後には影響しうる。
- 固定磁気センサーは環境変化の監視に使えるが、一地点の観測だけで部屋全体の歪みを修正できるとは限らない。

出典：[Polhemus G4 User Manual, Appendix B](https://polhemus.com/_assets/img/G4_User_Manual_URM10PH238-D.pdf)。同資料はAC方式の説明。今回の切替DCへの適用は、過渡応答を含めて別途検証する。

## G. 試作の概算と評価計画

### 線材の概算

参照会話に記された線径0.65 mm、長さ50 m、5 V電源を使う案。購入・到着状況は今回独立には確認していない。

| 項目 | 概算 |
|---|---:|
| 正方形の一辺 | 2.8 m |
| 巻数 | 4 |
| コイル部分の線長 | 44.8 m |
| 銅線断面積 πd²/4 | 約0.332 mm² |
| 抵抗率を0.0172 Ω·mm²/mとした抵抗 | 約2.32 Ω |
| 5 Vを直接印加した定常電流 | 約2.15 A |
| 巻数×電流 | 約8.6 At（アンペアターン） |
| コイルの定常消費電力 I²R | 約10.8 W |

配線・シャント・ドライバの電圧降下、温度上昇による抵抗増加を無視した概算。平均電力は駆動デューティ比にもよる。単巻経路が重なった理想正方形コイルの中心なら B = 2√2 μ₀NI/(πa) より約3.5 µTになるが、中心の場の大きさから位置精度は分からない。

駆動回路では電流反転と電流の減衰経路を設け、過電流・発熱を管理する。MOSFETを4個並べただけでHブリッジが完成するわけではなく、ゲート駆動や同時導通防止も必要。初期評価で測るのはR、L、実電流と整定時間。実装回路図の設計はこの発表アウトラインの範囲外。

### 実測の順序と判定材料

| 段階 | 実験 | 残す結果 |
|---|---|---|
| 静止1点 | +I / 0 / −Iを反復 | 電流波形、各軸磁場、整定時間、平均時間とノイズの関係 |
| 既知位置の格子 | 位置と姿勢を固定して移動 | 理論場との残差、位置方向ごとの勾配、繰返し再現性 |
| 複数モード | コイルごとの観測を取得 | 位置・姿勢の局所感度、離れた状態間の曖昧性 |
| 動的融合 | 同じ軌跡を複数回動く | IMUのみとの比較、独立基準に対する位置・姿勢誤差 |
| 30分装着 | 静止・歩行・屈伸などを含む | 時間に対するドリフト、手動リセット回数、補正時の跳び |
| 環境変化 | 金属家具の移動など | 異常の検出、復帰時間、地図再較正の必要性 |

「誤差」は独立基準に対して測る。磁場モデルとの残差が小さいだけでは、真の位置が正しい証明にはならない。中央値とP95、評価範囲、運動条件、測定時間を併記し、静止精度と動的精度を分ける。

## 用語の短い説明

| 用語 | 発表での説明 |
|---|---|
| Pose | 物体の位置と姿勢の組 |
| IMU | 加速度計とジャイロなどを組み合わせた慣性センサー |
| Bias | 真値に対して加算される測定値の偏り。静止中にも現れる |
| Yaw | 鉛直軸まわりの向き |
| Occlusion | 光やカメラから対象が隠れること |
| TDMA | 複数の信号源を時間で分けて測ること |
| Field map | 位置ごとの磁場ベクトルを記した地図 |
| Localization | 既知の地図に対して現在位置を推定すること |
| SLAM | 地図と自己位置を同時に推定すること |
| Observability | 観測から未知の状態を区別できるかという性質 |
| Fixed-lag smoothing | 最近の一定時間分の状態を保持し、後から来た観測も使って修正する方法 |
| CRLB | 一定の仮定の下で推定分散がどこまで小さくなりうるかを表す理論的下限 |
