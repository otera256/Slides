# 原理図の編集

`tracking.typ` はCeTZで作った編集可能な模式図です。図の出力は幅24 cm程度、文字16〜22ptを基本にしています。`main.typ` で全幅表示し、縮小して細い列へ押し込まない構成です。製品写真やValveの原図は `../product-image-slides.typ` に分かれています。

| 関数 | 図の説明 |
|---|---|
| `pose` | 移動3方向と回転3軸。ヨーは上面、ピッチは側面、ロールは正面から描く |
| `skeleton` | 頭・手が同じでも脚の候補が残ることと、腰・足の追加観測。脚のリンク長は各候補で共通 |
| `lighthouse` | 受光時刻から掃引角を得て、既知の素子配置と照合する流れ。1回の掃引の断面 |
| `cameras` | カメラの設置側と、観測する対象・目印。淡い扇形は視野の模式図 |
| `architecture` | 独立駆動するコイル、電流測定、磁気・IMU、時刻同期、無線、推定、VR出力 |
| `field-gradient` | 同じ磁場ノイズ幅を位置軸に写した局所近似。勾配が大きいほど位置の不確かさが小さい |
| `reversal` | 電流と磁気観測を同じ時間軸で並べ、背景30 µT・コイル±2 µTの例を説明 |
| `tdma` | A/B/Cを200 msずつ観測する例。各50 ms区間の灰色部は捨て、安定した測定窓を利用 |
| `field-match` | 候補位置で磁場を計算し、姿勢で座標変換して観測と比較する反復 |
| `fusion` | 測定時刻と到着時刻を区別し、過去を補正して保存済みIMUで現在まで再計算 |

これらは実測データや実装済み回路の図ではありません。磁場勾配の図は姿勢固定・1次元で磁場の1成分を扱い、3次元の観測可能性を保証しません。反転差分は位置・姿勢・背景・電流振幅の条件を本編と補足で説明します。時分割の灰色部の幅と600 ms周期は例であり、実測した整定時間ではありません。

図の色だけに意味を依存させず、文字・点・線種も併用しています。ラベルを増やす場合は文字を小さくせず、まず語を短くするか図の配置を調整してください。共通テーマの本文・キャプションは20pt、表は18pt、出典は従来の11ptです。
